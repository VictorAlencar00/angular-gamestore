## ⚡ Development

### 🖥️ Development Server

Run the command below to start a local development server:

```bash
ng serve
```

Run the command below to start json-server (db simulator) serving on:

```bash
json-server --watch db.json
```

After running the command, navigate to:  
[http://localhost:4200/](http://localhost:4200/)

The application will automatically reload whenever you change any of the source files.

---

### 🛠️ Code Scaffolding

Generate new components or other Angular elements with:

```bash
ng generate component component-name
```

🏗️ Build
Build the project for production using:

```bash
ng build
```

🔍 Running Unit Tests
Execute unit tests via Karma:

```bash
ng test
```

🧪 Running End-to-End Tests
Run end-to-end tests with:

```bash
ng e2e
```
